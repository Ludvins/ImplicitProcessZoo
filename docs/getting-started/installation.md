# Installation

Implicit Process Zoo supports Python 3.10 through 3.12. Continuous integration
tests Python 3.10 and 3.12 on CPU.

## Editable research environment

Clone the repository, create a virtual environment, and install the complete
editable environment:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

`requirements.txt` delegates to the optional dependency groups in
`pyproject.toml`. It installs the experiment, vision, tracking, test, and
documentation tools used by contributors.

## Minimal library install

For the model library without experiment extras:

```bash
python -m pip install -e .
```

Install only the extras you need:

```bash
python -m pip install -e ".[experiments]"
python -m pip install -e ".[experiments,vision,tracking]"
python -m pip install -e ".[test,docs]"
```

## CPU and accelerator builds

PyTorch wheels are platform-specific. For a CPU-only environment, install the
CPU wheel using the command generated by the
[official PyTorch selector](https://pytorch.org/get-started/locally/) before
installing this project. For CUDA or another accelerator, select the matching
platform command there instead.

The repository also contains `requirements/lock-cpu-py312.txt`, a frozen
Python 3.12 CPU environment used for reproducibility. Install it only on a
compatible platform:

```bash
python -m pip install -r requirements/lock-cpu-py312.txt
```

## Verify the environment

```bash
python -c "import implicit_process_zoo; print(implicit_process_zoo.__version__)"
python -m experiments.uci.benchmark --help
```

The expected package version is `0.1.0`.
