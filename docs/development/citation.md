# Citation and license

## Citation

GitHub can generate citation formats directly from the repository's
`CITATION.cff`:

```yaml
title: Implicit Process Zoo
author: Luis A. Ortega
version: 0.1.0
type: software
repository: https://github.com/Ludvins/ImplicitProcessZoo
```

If a specific inference method or dataset supports the work, also cite its
original paper or dataset record. The [references](references.md) page lists
the method papers. The ELD experiment requires the dataset attribution and
license described in its [experiment page](../experiments/eld.md).
