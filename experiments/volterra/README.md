# Lotka--Volterra Simulator Prior

This package contains target generation, model runners, metrics, and plots for
the vector-output Lotka--Volterra experiment.

See the [canonical experiment guide](https://ludvins.github.io/ImplicitProcessZoo/experiments/volterra/)
for presets, exact figure commands, outputs, and package layout.

```bash
python -m experiments.volterra.run --help
```
