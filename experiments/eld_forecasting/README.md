# Electricity Load Forecasting

This package implements the single canonical 24-hour-context,
24-hour-forecast ELD paper protocol with corrected index-based metrics and
explicit reporting.

See the [ELD guide](https://ludvins.github.io/ImplicitProcessZoo/experiments/eld/)
for UCI attribution, preparation, exact rerun/figure commands, sharding,
methodology, and the output schema.

```bash
python -m experiments.eld_forecasting.run --help
```
