# Simulator-Prior Forecasting

This package implements the randomly forced damped-oscillator forecasting
benchmark.

See the [simulator-forecasting guide](https://ludvins.github.io/ImplicitProcessZoo/experiments/simulator-forecasting/)
for presets, T_obs=15 figure reproduction, comparisons, and outputs.

```bash
python -m experiments.simulator_forecasting.run --help
```
